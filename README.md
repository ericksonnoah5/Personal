# Personal

A personal portfolio website introducing Noah Erickson and his programming projects.

## Overview

A small, static portfolio built with HTML and CSS. It presents a biography, a summary of projects across several programming languages, and a contact link.

## Features

- About, projects, and contact sections with in-page navigation.
- Profile and project images stored alongside the page.
- Lightweight layout with no JavaScript or build dependencies.

## Tech stack

- HTML5
- CSS3

## Getting started

```bash
git clone https://github.com/ericksonnoah5/Personal.git
cd Personal
python3 -m http.server 8000
```

Open [localhost:8000](http://localhost:8000). Python 3 is only needed for this local server; the page can also be opened directly from `index.html`.

## Project structure

```text
index.html      Page content and navigation
style.css       Page styles
myPhoto.png     Profile image
pic.png         Project image
about.txt       Empty draft file
portfolio.txt   Empty draft file
```

## Status

An early portfolio project. Project descriptions are summaries rather than individual case studies. There is no build step or automated test suite.
